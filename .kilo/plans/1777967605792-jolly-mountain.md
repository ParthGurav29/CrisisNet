# Gemma AI Layer Implementation Plan for CrisisNet

## Overview

This plan outlines the implementation of the Gemma AI layer for CrisisNet, an offline emergency communication app. The AI must work completely offline after initial setup, using a GGUF model downloaded on first launch.

## Current State Analysis

### Existing Infrastructure
- `src/ai/llamaService.js` - Existing llama.rn service (uses different model path)
- `src/screens/AskAI.jsx` - Basic AI screen implementation
- `src/screens/Triage.jsx` - Placeholder triage screen
- `src/context/AIContext.jsx` - Empty file
- `package.json` - Has `llama.rn` dependency
- `AndroidManifest.xml` - Has INTERNET permission

### Required Changes
The existing implementation uses `llama.rn` which is different from the requirements. Need to:
1. Keep existing `llama.rn` (already installed)
2. Add `react-native-progress` for download UI
3. Implement new model download flow
4. Create proper AI context and prompts
5. Update Triage screen with AI integration

## Task 4: MODEL LOADING SERVICE

### File: `src/ai/gemma.js` (rewrite existing)

**Parameters:**
- `n_ctx: 512` (context window)
- `n_threads: 4` (CPU threads)
- `n_gpu_layers: 0` (CPU only)
- `temperature: 0.1` (deterministic for emergencies)

**Exports:**
```js
- loadModel() → Promise<boolean>
- isModelLoaded() → boolean
- generateResponse(prompt) → Promise<string>
- unloadModel() → void
```

**Error Handling:**
- File not found → clear error
- Out of memory → fallback message
- 30-second timeout for inference

## Task 5: SURVIVAL PROMPT TEMPLATE

### File: `src/ai/prompts.js` (new)

**Function: `buildSurvivalPrompt(userQuestion)`**

**Template:**
```
System: You are CrisisNet AI, an emergency survival assistant.
Rules:
- Respond with SHORT numbered steps only
- Start response with emergency name in CAPITALS
- Give most critical action as Step 1
- Use plain language — no medical jargon
- Maximum 8 steps per response
- End with: when to call emergency services
- Never give vague answers — always be specific

Question: {userQuestion}
```

## Task 6: TRIAGE PROMPT TEMPLATE

### File: `src/ai/triage.js` (new)

**Function: `buildTriagePrompt(inputs)`**

**Inputs:**
- `breathing: boolean`
- `severeBleeding: boolean`
- `conscious: boolean`
- `canMove: boolean`
- `description: string` (optional)

**Output:**
```js
{
  tag: 'RED' | 'YELLOW' | 'GREEN' | 'BLACK',
  reason: string
}
```

**Prompt:**
```
Classify this patient's triage level based on:
- Breathing: {inputs.breathing}
- Severe bleeding: {inputs.severeBleeding}
- Conscious: {inputs.conscious}
- Can move: {inputs.canMove}
- Notes: {inputs.description}

Respond ONLY with the triage tag and one sentence reason.
```

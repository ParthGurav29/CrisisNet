# CrisisNet Mesh Messaging Fix Plan

## Current State Analysis

### Issues Found

1. **Mesh Auto-start: NOT IMPLEMENTED**
   - `meshService.init()` called in App.jsx but mesh events not fully wired
   - No automatic start when Home screen loads
   - `started` event not emitted by SDK (need to verify)

2. **Peer Identity: MISSING**
   - Device ID generated randomly each launch: `user_${Math.random().toString(36).substring(2, 9)}`
   - No persistent storage of device ID
   - No short ID display in UI

3. **Chat Screen: INCOMPLETE**
   - No node count display
   - No sender short ID in messages
   - No emergency message styling
   - Message persistence on send not working correctly
   - No auto-scroll to bottom

4. **Home Screen: MISSING STATUS INDICATORS**
   - No animated pulse for SEARCHING state
   - No tap-to-open-chat functionality

5. **Message Structure: INCONSISTENT**
   - `sender_id` vs `sender` field inconsistency
   - Timestamp format inconsistent

6. **Missing Dependencies**
   - `@react-native-async-storage/async-storage` not in package.json but used in OnboardingScreen

## Implementation Summary

### Key Changes Made:

1. **Persistent Device ID** (`src/storage/deviceId.js`)
   - Generates UUID v4 on first launch
   - Stores in AsyncStorage under key `device_id`
   - Returns short ID (first 6 chars) for display

2. **Mesh Service** (`src/mesh/meshService.js`)
   - Uses persistent device ID from AsyncStorage
   - Emits `scanning` and `advertising` events after start
   - Exposes `getDeviceShortId()` method

3. **Mesh Context** (`src/context/MeshContext.jsx`)
   - Initializes mesh on component mount
   - Tracks `scanning` and `advertising` state
   - Proper message structure with `sender_id`
   - Auto-cleanup at 500 messages

4. **Chat Screen** (`src/screens/Chat.jsx`)
   - Header shows "Mesh Chat" + node count
   - Sent messages: right aligned, blue background
   - Received messages: left aligned
   - Emergency messages: red/yellow/green border
   - Auto-scroll to bottom
   - Send button with loading spinner

5. **Home Screen** (`src/screens/Home.jsx`)
   - Tap on status row opens Chat
   - Shows "X device(s) connected"
   - Status indicator with color coding

6. **Mesh Status** (`src/components/MeshStatus.jsx`)
   - Green pulse when connected with nodes
   - Yellow pulse when searching
   - Red when offline

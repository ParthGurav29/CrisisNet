# Model Download & Loading Verification Plan

## Problem Analysis

Based on codebase review, the following issues exist:

### 1. No Resume Capability
- **Location**: `src/utils/modelStorage.js:837-842, 1001-1003`
- **Issue**: When download fails, temp file is deleted and download restarts from 0%
- **Impact**: Users with unstable connections must re-download entire 2.8GB model

### 2. Progress Bar Accuracy Issues
- **Location**: `src/screens/ModelDownloadScreen.jsx:135-137`
- **Issue**: Speed calculation converts MB to bytes incorrectly (multiplied by 1024*1024)
- **Impact**: Progress and speed display are inaccurate

### 3. No Pre-Download File Verification
- **Location**: `src/utils/modelStorage.js` - `downloadModel` function
- **Issue**: Download proceeds without checking for existing partial downloads
- **Impact**: Wasted bandwidth, no resume capability

### 4. Model Loading Progress Not Detailed
- **Location**: `src/ai/gemma.js:87-211`
- **Issue**: Model loading shows only 30%, 90%, 100% - no real progress
- **Impact**: UI appears stuck during long loading phases

### 5. Lock File Not Properly Managed
- **Location**: `src/utils/modelStorage.js:337-392`
- **Issue**: Lock file doesn't store download progress, can't detect partial downloads
- **Impact**: App can't resume interrupted downloads

// Add after existing constants (around line 48):
const PARTIAL_DOWNLOAD_THRESHOLD = 10 * 1024 * 1024; // 10MB

// Add new function to check for partial download:
export const getPartialDownloadInfo = async () => {
  try {
    if (!(await RNFS.exists(TEMP_MODEL_PATH))) return null;
    const stat = await RNFS.stat(TEMP_MODEL_PATH);
    const size = parseInt(stat.size, 10);
    if (size < PARTIAL_DOWNLOAD_THRESHOLD) {
      await RNFS.unlink(TEMP_MODEL_PATH);
      return null;
    }
    return { bytesDownloaded: size, totalBytes: MODEL_EXPECTED_SIZE };
  } catch (e) {
    return null;
  }
};

// Modify writeLockFile to include progress:
const writeLockFile = async (lockData) => {
  const content = JSON.stringify(lockData);
  await RNFS.writeFile(LOCK_PATH, content, 'utf8');
};
